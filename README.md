# Lunar Lion Dance

To start a local development server, run:

```bash
ng serve
```

To build the project run:

```bash
ng build
```
To deploy to cloudflare pages, either:

1. Push to remote github repo
2. Or run a shorthand for the wrangler pages deploy command:

```bash
npm run deploy
```

3. Or run the full wrangler command directly:

```bash
npx wrangler pages deploy
```
